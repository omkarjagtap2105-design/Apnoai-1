## Features

- **Dark/Light theme toggle** with `localStorage` persistence (dark mode is default)
- **Responsive design** — works on desktop, tablet, and mobile
- **Smooth scrolling navigation** with anchor links
- **Four sections:** Hero (Home), About, Skills, Contact
- **Contact cards** with clickable email (mailto), GitHub, and LinkedIn links
- **Hover animations** on cards and buttons
- **Hero fade-in animation** on page load
- **Accessibility:** semantic HTML5, `aria-label`s, `focus-visible` outlines
- **No frameworks** — pure HTML/CSS/JS

## Vercel Deployment Instructions

1. Create a Vercel account at [vercel.com](https://vercel.com) using your GitHub account
2. Go to the Vercel dashboard and click **"New Project"**
3. Import the GitHub repository you just uploaded
4. Configure the project:
   - **Framework Preset:** select **"Other"** (static HTML — no framework)
   - **Build Command:** leave **empty** (no build step needed)
   - **Output Directory:** leave **empty** (root — `index.html` is in project root)
   - **Install Command:** leave **empty** (no npm dependencies)
5. Click **"Deploy"**
6. Wait for the deployment to complete
7. Your portfolio is live! Copy the Vercel URL to share

> **Important:** `index.html` must be in the project root for Vercel to detect and serve it automatically. No `vercel.json` or build configuration is needed for a static site.
